# Entrega S01 - pagatu-orden-ms

Este paquete contiene la documentación MkDocs de la actividad autónoma S01.

## Generar / visualizar

```bash
pip install mkdocs-material
mkdocs serve
```

Para entregar el PDF, abre la documentación en MkDocs y usa **Imprimir → Guardar como PDF**. El nombre solicitado por la guía es:

`S01_Equipo##_ApellidoNombre.pdf`

Antes de entregar:
- reemplaza los datos de estudiante/equipo/GitHub;
- revisa y personaliza el feedback;
- verifica que las capturas originales cumplan el requisito de reloj del sistema + usuario/perfil visible.
