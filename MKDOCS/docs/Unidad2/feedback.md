# Feedback personal

**Jannys Graciela Navarro Acrota · Casa o Nada**

Este anexo requiere respuestas personales de la estudiante para cada sesión. No se inventan autoevaluaciones, satisfacción ni experiencias de clase.

Para S06, S07, S08, S09 y S10, completar:

- Aprendizaje más importante.
- Punto confuso o duda.
- Pregunta para la siguiente clase.
- Comprensión: entendido / más o menos / necesito ayuda.
- Ayuda que permitiría comprender mejor.
- Participación: muy comprometida / comprometida / poco comprometida.
- Satisfacción del 1 al 10.

Las reflexiones técnicas de las páginas son borradores para revisar y defender; no afirman una experiencia personal que no haya sido confirmada. Falta el número de equipo para utilizar exactamente la nomenclatura de PDF solicitada por el docente.
